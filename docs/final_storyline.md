# 최종 발표 스토리라인

**중심 문장:** “공개 원자료에서 평가 차이는 관측됐지만, 공정성 판단에는 집단·label·위치·측정 방식을 분리한 검증이 필요하다.”

**Assumption:** 발표 시간 10분, 본문 10장 + 부록. 실제 수업 시간에 맞춰 5·8장을 부록으로 옮길 수 있다. 그림의 기술 표기는 영어로 유지했고, 아래 한국어 제목·해설을 슬라이드에 붙인다. 발표 덱 파일 자체는 이번 산출물에 포함하지 않는다.

## 1. 질문: 생성형 AI가 평가하면 공정한가? (40초)

한 문장: “우리는 모델의 공정성 순위를 만드는 대신, 공개 원자료에서 어떤 차이가 재현되는지 확인했다.”

화면: 연구 질문과 두 출처만 제시. LLM 채용 전반에 대한 찬반 선언으로 시작하지 않는다.

연결: “두 연구는 서로 다른 평가 방식을 사용한다.”

## 2. 두 연구, 두 종류의 측정 (50초)

| PNAS | Rozado |
|---|---|
| 이력서 점수, 성별·인종 교차집단 | 두 후보 선택, 이름·A/B label·제시 위치 |
| 단위: score points | 단위: 선택 %, 조건 간 차이는 pp |
| 5모델 핵심 회귀, 4모델 공통 표본 | 22모델, name/order/masking |

발표: “단위와 실험이 달라 하나의 Fairness Score로 합치지 않았다.”

## 3. 우리가 추가한 것: 원자료에서 결과까지 추적 (50초)

화면 흐름: raw + hash → 정제 표 → pair/회귀 membership → 추정치 → 자동 생성 그림.

발표: “모든 제외를 기록하고 missing을 채우지 않았다. 예를 들어 Rozado name은 108개 문제 행이 속한 86개 pair를 주 분석에서 제외하되 정제 표에 보존했다.”

원 논문 결과를 옮긴 것이 아니라 Python secondary pipeline을 구축했다는 점을 설명한다.

## 4. PNAS: 집단을 묶으면 보이지 않는 차이 (70초)

그림: [01_pnas_intersection](../figures/final/01_pnas_intersection.svg).

슬라이드 제목: **성별·인종 교차집단별 점수 격차의 방향이 달랐다.**

발표: “White male 대비 15개 대비 중 14개가 Holm 보정 후 유의했다. 그러나 점추정치 절댓값은 모두 1점 미만이다. 유의성과 실제 선발에서의 중요성은 별개다.”

작은 주석: 0–100 점수 척도 / 모델별 표본 상이 / pointwise 95% CI / 공정성 순위 아님.

## 5. 모델을 비교하려면 표본부터 맞춰야 한다 (40초)

그림: [A1_pnas_model_contrasts](../figures/final/A1_pnas_model_contrasts.svg), 시간이 짧으면 부록.

발표: “공통 295,672행에서 18개 집단 격차 차이 중 12개가 유의했다. 이것은 같은 행에서 계산한 signed gap의 차이이지, 더 공정한 모델의 순위가 아니다.”

## 6. Rozado name: 이름 할당에 따른 선택 차이 (70초)

그림: [02_rozado_name](../figures/final/02_rozado_name.svg).

슬라이드 제목: **이름 조건에서 Female 선택은 53.29%–61.78%였다.**

발표: “적격 15,313개 pair에서 22모델 모두 50%보다 높았다. 같은 CV 내용에 이름 배치를 교환한 pair를 사용했고 직업 clustering과 Holm 보정을 적용했다.”

연결: “그러면 이름을 가리면 끝일까?”

## 7. 마스킹 결과를 읽기 전에 A/B 배정을 확인 (70초)

그림: [04_rozado_labels](../figures/final/04_rozado_labels.svg).

화면 설명: fixed = 원래 Male→A, Female→B / counterbalanced = 이 대응을 교차 배정 / A≠항상 첫 후보.

발표: “fixed에서는 A/B label 선호와 원래 성별이 얽힌다. counterbalanced에서도 A 선택 비율이 50%와 다른 모델은 132검정 보정 후 12개였다. 이름을 지우는 것과 label 영향을 없애는 것은 같은 작업이 아니다.”

## 8. 원래 성별 역매핑은 50% 근처로 모였다 (80초)

주 그림: [06_rozado_masked_assignment](../figures/final/06_rozado_masked_assignment.svg).
보조/부록: [05_rozado_masking_changes](../figures/final/05_rozado_masking_changes.svg).

발표: “counterbalanced의 원래 Female 선택은 49.21%–51.86%였고, 보정 후 유의한 모델은 없었다. 공통 pair에서 name 대비 선택 비율은 모두 감소했으며 22개 중 21개가 별도 44검정 보정 후 유의했다. 다만 차이를 검출하지 못했다는 것은 동등성이나 편향 제거의 증명이 아니다.”

작은 주석: 역매핑 gender / proxy 가능성 / 새 생성 응답 / causal improvement 아님.

## 9. 첫 후보 선택의 치우침도 남는다 (70초)

그림: [03_rozado_position](../figures/final/03_rozado_position.svg).

발표: “첫 후보 선택 비율은 조건에 따라 큰 차이가 보인다. 하지만 이 pair는 이름을 교환했을 뿐 CV 내용의 순서를 뒤집지 않았다. 따라서 내용을 통제한 순서의 인과효과라고 부르지 않는다. 확인 가능한 현상과 증명하지 못한 원인을 구분하는 것이 이번 분석의 핵심이다.”

order 파생 자료를 독립 응답으로 중복 집계하지 않았음을 덧붙인다.

## 10. 결론: 단일 숫자보다 분리된 검증 (60초)

화면에 세 문장:

1. 교차집단 점수 차이와 선택 비율 차이가 관측됐다.
2. masking 지표가 50%에 가까워져도 label·위치 지표와 자료의 한계는 남는다.
3. 재현 가능한 원자료·분모·provenance가 있어야 결론의 범위를 설명할 수 있다.

마지막 말: “이번 과제는 AI 채용이 항상 공정하거나 항상 불공정하다는 선언이 아니다. 공개 데이터에서 확인한 차이와 확인하지 못한 한계를 함께 제시한 재분석이다.”

## 예상 질문과 답변

- **가장 공정한 모델은?** 이 연구는 그런 순위를 계산하지 않았다. 연구별 metric·표본·모델 버전이 다르고 절대 편향 비교도 아니다.
- **masking으로 편향이 없어졌나?** counterbalanced의 원래 성별 역매핑에서 50% 차이를 검출하지 못했다. 동등성 검정이나 실제 공정성 증명은 아니다.
- **첫 후보가 유리한 이유가 위치 때문인가?** 내용과 위치를 분리하는 CV 순서 교환을 이 자료에서 확인하지 못했으므로 단정할 수 없다.
- **논문을 완전히 재현했나?** PNAS 저자 코드 annotation은 계수 30/30, CI 59/60 일치했다. 미세 불일치 1개를 유지했다. Rozado는 최종 논문 figure별 대응이 미확정이며 우리 명세로 재분석했다.
- **다중검정은?** PNAS 15/18, Rozado name 각 22, 확장 진단 132, 대응 변화 44를 명시된 별도 family로 Holm 보정했다. 그림 CI는 동시 구간이 아니다.
- **나머지 실험은?** name_gender·pronouns·CV score는 구조 확인까지 했고 추가 분석은 범위 밖으로 종료했다.
