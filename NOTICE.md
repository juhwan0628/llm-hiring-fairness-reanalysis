# Public repository notice

This repository contains original analysis code, validation scripts, aggregate statistical outputs, reports, and figures created for a secondary analysis of publicly available research data.

## Third-party data

The underlying PNAS Nexus replication data and Rozado/Zenodo experimental data are **not redistributed in this repository**. Their copyrights and licenses remain with their respective authors and publishers. Source identifiers, checksums, citations, and acquisition metadata are retained under `data/metadata/` so users can obtain the data from the original sources where permitted.

Row-level derived tables that could substantially reproduce the source datasets are also excluded. The public repository contains aggregate estimates and visualizations sufficient to document the reported analysis without republishing the underlying records.
